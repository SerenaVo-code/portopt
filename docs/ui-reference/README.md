# Ảnh giao diện tham khảo

Các ảnh trong thư mục này do người học cung cấp để lưu cùng project. Người học xác nhận đã yêu cầu Claude Code tham khảo thiết kế UI khi xây dựng giao diện. Prompt được cung cấp lại nguyên văn là: “Mình đã thiết kế giao diện trong các hình đính kèm. Hãy xem kỹ bố cục, màu sắc, kiểu chữ, khoảng cách và cách sắp xếp các thành phần, rồi chỉnh giao diện trong project để bám sát thiết kế đó”. Thời điểm gửi ban đầu không còn trong bản lưu; ghi chú tương ứng nằm trong `PROMPTS.md` và `PROMPT_DECISION_HISTORY.md`.

Ảnh chỉ dùng làm tư liệu tham khảo trực quan. Chúng không phải chỉ dẫn mới về thuật toán, dữ liệu hay hành vi của project.

- `0 · Tổng quan 4 module.png` — màn hình tổng quan.
- `2 · Phân công đội (tham lam, bước 4 6).png` — module phân công đội.
- `3 · Quỹ giờ công (quy hoạch động, ô dp[3][8]).png` — module quỹ giờ công.
- `4 · Xếp container (first-fit giảm dần, bước 5 8).png` — module xếp container.
